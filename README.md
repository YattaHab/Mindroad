# 🧠 MindRoad

**MindRoad** is a structured learning platform that helps developers navigate their learning journey through curated tracks and roadmaps — from complete beginner to job-ready professional.

Instead of getting lost searching for what to learn next, MindRoad gives you a clear, step-by-step path with hand-picked resources, real projects to build, and progress tracking every step of the way.


## 🌟 What is MindRoad?

MindRoad solves a problem every developer faces: **"What should I learn, and in what order?"**

The platform organizes learning into **Tracks → Roadmaps → Levels → Topics → Resources**, giving each user a personalized, structured path with everything they need in one place.


## ✨ Features

- 🗺️ **Structured Roadmaps** — Curated learning paths across multiple tech tracks, broken into Beginner, Intermediate, and Advanced levels
- 📚 **Curated Resources** — Hand-picked videos, courses, books, and articles for every topic — both free and paid
- ✅ **Progress Tracking** — Mark resources as done and watch your completion percentage update in real time
- 🏗️ **Projects** — Each level ends with a real project. Submit it to unlock the next level
- 🏆 **Certificates** — Earn a certificate automatically upon completing an entire roadmap
- 🔖 **Bookmarks** — Save any resource to revisit later
- 💬 **Topic Discussions** — Ask questions and share insights through threaded comments on every topic
- ⭐ **Roadmap Reviews** — Rate and review roadmaps to help other learners
- 🔥 **Streaks** — Stay consistent with a daily activity streak tracker
- 🔔 **Notifications** — Get notified on level completions, replies, new resources, and more
- 💳 **Subscription Plans** — Free plan for getting started, Premium plan for full access
